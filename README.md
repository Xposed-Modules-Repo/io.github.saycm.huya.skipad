# 虎牙广告跳过模块

面向 LSPosed 的虎牙广告过滤模块，基于 libxposed API 102 开发，适配虎牙 **13.5.44**（versionCode `117129`）。

## 功能

- 拦截开屏广告。
- 过滤推荐列表中的广告卡片。
- 拦截自动推广弹窗和直播间外普通广告请求。
- 点击“看广告赚虎粮”等奖励广告入口时，直接完成原奖励完成、关闭和发奖流程。
- 支持小程序游戏的自定义广告领取和激励视频奖励回调。
- 阻止小程序自定义广告横幅挂载，避免领奖确认时误触下方广告。
- 拦截直播间自动弹出的推广卡片、小游戏推广和原生广告浮窗。
- 清空直播间顶部活动推广横幅，保留任务进度横幅。

- 过滤标记为平台会员免展示的直播间广告弹窗。
- 实验性 4K 播放支持：对已下发的 4K 档位使用客户端会员播放分支；实际画质和播放可用性取决于直播源、设备及服务端鉴权。
- 每天首次打开虎牙、登录就绪后，为已有粉丝牌后台打卡。
- 支持自行配置直播间和每日赠送数量，只使用免费虎粮，库存不足时跳过，不购买。
- 在虎牙进程内保存日志和每日去重记录，查看日志时同步到模块，无需模块自启动。

## 安装

1. 安装模块，并在 LSPosed 中启用。
2. 将作用域设置为虎牙 `com.duowan.kiwi`。
3. 强制停止虎牙并重新打开。

## 版本变动

- 1.16：增加每日首次打开后的粉丝牌打卡和定向免费虎粮赠送；配置位于虎牙详情页，日志使用统一毛玻璃样式的独立页面；增加每日去重、执行结果记录和日志同步，自动任务默认关闭，无需模块自启动。

- 1.15：补充平台会员免展示广告过滤，增加实验性 4K 客户端播放分支，保留登录检查和账号会员状态；应用名更改为 FuckAD，功能开关移入详情页，主页增加真实框架加载状态检测。

- 1.14：覆盖普通弹窗、占位弹窗及 H5 / 小程序悬浮窗口入口，拦截直播间自动推广、游戏联运、电商活动及原生广告浮窗，保留其他手动窗口和奖励入口。
- 1.13：阻止小程序广告横幅挂载，保留领奖成功回调。
- 1.12：补充小程序游戏自定义广告领取入口，修复 Map 类型广告参数无法读取的问题。
- 1.11：修复动态补丁加载后业务 Hook 未命中的问题，补充推荐广告回填、沉浸式推荐和列表写入时的广告过滤。
- 1.10：迁移至 libxposed API 102，使用现代模块元数据、包加载完成回调和拦截链接口。
- 1.9：更新 Application ID，适配虎牙 13.5.44，覆盖开屏、推荐列表、自动推广和奖励广告流程。
- 1.8：增加开屏广告、推荐列表广告和自动推广弹窗拦截。
